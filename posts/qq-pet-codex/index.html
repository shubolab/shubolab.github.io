QQ 宠物赛博复活：这次它不吃元宝

Codex 有桌宠了，我把退役多年的 QQ 企鹅叫回来上班。为了让它顺利入职，还补了一套有点过分的 QA。

2026-08-09Shubo4 min

看到 Codex 支持桌面宠物时，我脑子里第一个候选不是猫，而是那只住过任务栏右下角的企鹅。小时候怕它饿，现在只希望它别在我跑任务时突然散架。

于是有了 QQpet-codex：一套 Codex v2 宠物包，附带安装 Skill、重建脚本和 QA 记录。做完才发现，我给企鹅准备的发布证据，比一些内部项目还齐。

先把企鹅塞进 8 × 11 个格子

Codex v2 只认固定规格：1536 × 2288、8 列 11 行、每格 192 × 208、RGBA 无损 WebP，spriteVersionNumber 必须是 2。动作放错一格，企鹅可能在任务失败时热情挥手。情绪很稳定，时机不太对。

图集里有 idle、hover、thinking、review、waiting、waving、failed、左右移动和 16 个看向方向。原来没问题的动作直接保留，没必要借“重制”之名把老朋友整得亲妈都不认识。

最费时间的动作叫“站着不动”

旧 idle 偏小又偏软，和 thinking 一切换，企鹅像突然退到两米开外。我重新做了六帧呼吸和完整眨眼，可见边界从约 130 × 146 提到 156 × 198。Hover 也顺手重画，因为原版站在旁边像临时缩水。

企鹅也有入职体检

16 个看向方向按新 idle 重新对齐，比例精确到 0.7096774193548387。不是故意炫小数点，少一点真的会抖。方向还做了三轮盲测——这大概是它职业生涯里最严格的一次入职体检。

PNG 和 WebP 解码后 0 个变化像素；干净重建与内置包字节一致；最终校验 0 错误、0 警告。听起来很过头，但总比发布说明写“肉眼看着还行”靠谱。

安装之前，先给自己留条后路

仓库级 Skill 在 .agents/skills/qqpet-codex。安装会先用临时 CODEX_HOME 预检，再备份旧版本，最后从真实目标路径复验。企鹅可以撞墙，安装脚本最好别学它。

只验证，可以在 Codex 里这样说：

使用 $qqpet-codex 只验证仓库内置的 QQpet-codex v2 宠物包，不要安装。

要安装，再明确授权：

使用 $qqpet-codex 安全安装仓库内置的 QQpet-codex v2 桌面宠物；
先用隔离的 CODEX_HOME 预检，再安装到我的真实 Codex 配置。

装完刷新宠物列表，重新选择 QQpet-codex。还没更新再重启 Codex，别一上来就拔电源。

最后

项目原创材料以 CC0 1.0 发布，来源链和第三方商标说明都在仓库里。它不是官方续作，只是我把小时候那只企鹅捡回来，按今天的习惯重新装好。

喂养按钮没回来，校验和倒是有了。也算长大了。
