战神本是去跑 Codex 的

这次回家要装的是一台远程桌面。WSL 的 SSH 只是顺手加的备用入口，它让 Windows Server 开不了机。

2026-09-27Shubo4 min

家里那台 J1900 继续当常驻入口。它弱，但很少需要我出现。这次能回家维护，我想上架的是闲置的神舟战神：性能够用，做成一台随时能进的完整桌面，远程跑 Codex 桌面版。

远程桌面不直接放到公网上。3389 的爆破太密，我也没有一套愿意长期维护的安全组。公网上我接受的还是 SSH，并且只允许密钥登录。

WSL 是顺手的第二件事。战神比 J1900 强，如果 WSL 里的 SSH 也能从公网进来，就多一个更强的 Linux 备用壳。正事是桌面，这一条只是备用。

Codex 配这层端口转发时，把 Windows Server 的启动虚拟化打开了。hypervisorlaunchtype 变成 Auto 之后，hypervisor 在系统起来之前就要加载。这台机器这一步过不去，Server 开不了机。

安全模式和组策略都得先进系统。服务、策略这一类补救也一样。它没进。两个晚上的准备耗在重装上，Codex 的桌面没有装成。

WSL 到此停用。下一步只试 Hyper-V 里的一台 Linux 虚拟机，看它能不能当那个更强的备用 SSH，同时别再碰宿主机的开机。还没有结果。
